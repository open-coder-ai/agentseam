## 1. What `agentseam install` writes

Wiring one handler for the pre-tool gate. agentseam owns only the entries it adds;
an uninstall removes exactly those and leaves anything else in the file alone.

`.github/hooks/agentseam.json`

```json
{
  "hooks": [
    {
      "command": "python3 guard.py",
      "event": "preToolUse"
    }
  ],
  "version": 1
}
```

## 2. The event the handler sees

The same situation for every agent: **a secret about to be written to a file.**

This agent sends:

```json
{
  "session_id": "example",
  "tool_input": {
    "command": "create",
    "file_text": "AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-KEY",
    "path": "/memories/repo/team.md"
  },
  "tool_name": "memory"
}
```

which agentseam normalizes to:

```
event    = pre_tool
tool     = memory
path     = /memories/repo/team.md
command  = None
content  = AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-
```

## 3. What each decision looks like coming back

### `Decision.allow()` -- the handler is happy

```json
{"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": "allow"}}
```

Exit code: `0`

### `Decision.deny()` -- the handler refuses

```json
{"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": "deny", "permissionDecisionReason": "secret detected in file content"}}
```

Exit code: `0`

### `Decision.ask()` -- the handler wants a human

```json
{"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": "ask", "permissionDecisionReason": "looks like a credential -- confirm?"}}
```

Exit code: `0`

### `Decision.rewrite()` -- the handler wants the input changed

```json
{"hookSpecificOutput": {"hookEventName": "PreToolUse", "permissionDecision": "allow", "updatedInput": {"content": "AWS_SECRET_ACCESS_KEY=<redacted>"}}}
```

Exit code: `0`
