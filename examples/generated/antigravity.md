## Every hook, one at a time

The story is held constant across agents so the pages compare: the same credential
heading for a memory file, the same failing test, the same prompt.

### 1. `pre_tool` — called `PreToolUse` here

Enforcement: **best-effort**.

The agent sends:

```json
{
  "conversationId": "example",
  "modelName": "gemini-3.6-flash-medium",
  "stepIdx": 3,
  "toolCall": {
    "args": {
      "CodeContent": "AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-KEY",
      "TargetFile": "AGENTS.md"
    },
    "name": "write_to_file"
  },
  "workspacePaths": [
    "/repo"
  ]
}
```

which normalizes to:

```
event    = pre_tool
tool     = write_to_file
path     = AGENTS.md
content  = AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-
```

This is the gate, so every decision is worth seeing.

**`Decision.allow()`** — the handler is happy

```json
{"decision": "allow"}
```

Exit code: `0`

**`Decision.deny()`** — the handler refuses

```json
{"decision": "deny", "reason": "secret detected in file content"}
```

Exit code: `0`

**`Decision.ask()`** — the handler wants a human

```json
{"decision": "ask", "reason": "looks like a credential -- confirm?"}
```

Exit code: `0`

**`Decision.rewrite()`** — the handler wants the input changed

> reduced to `ask`: this agent cannot rewrite

```json
{"decision": "deny", "reason": "redacting the secret (Antigravity cannot modify a tool call)"}
```

Exit code: `0`

**`Decision.vouch()`** — the handler actively approves

> reduced to `allow`: this agent cannot vouch

```json
{"decision": "allow"}
```

Exit code: `0`
