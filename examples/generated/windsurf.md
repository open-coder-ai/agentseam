## Every hook, one at a time

heading for a memory file, the same failing test, the same prompt.

### 2. `pre_tool` — called `pre_run_command` here

Enforcement: **best-effort**.

The agent sends:

```json
{
  "hook_event_name": "pre_run_command",
  "tool_info": {
    "command_line": "echo 'AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-KEY' >> AGENTS.md"
  },
  "trajectory_id": "example"
}
```

which normalizes to:

```
event    = pre_tool
tool     = pre_run_command
command  = echo 'AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-KEY' >> AGENTS.md
```

This is the gate, so every decision is worth seeing.

**`Decision.allow()`** — the handler is happy

_No output; the exit code carries the answer._

Exit code: `0`

**`Decision.deny()`** — the handler refuses

```
secret detected in file content
```

Exit code: `2`

**`Decision.ask()`** — the handler wants a human

```
looks like a credential -- confirm? (this agent cannot prompt for confirmation; blocking instead)
```

Exit code: `2`

**`Decision.rewrite()`** — the handler wants the input changed

> reduced to `ask`: this agent cannot rewrite

```
redacting the secret (this agent cannot rewrite tool input; blocking instead)
```

Exit code: `2`
