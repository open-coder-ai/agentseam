## What agentseam claims

| | |
|---|---|
| tier | `block` |
| enforcement at `pre_tool` | **best-effort** |
| can block / transform | yes / no |
| hooks covered | 4 |
| hook config | `.devin/hooks.json` |
| evidence | `third-party-install` — a real working installation (.windsurf/hooks.json + hook scripts) in PaloAltoNetworks/prisma-airs-integrations; vendor docs unreachable from this network |

Exit code 2 is the ONLY block signal: no stdout decision protocol, no machine-readable reason, no rewrite. Critically there is NO file-write event -- prompt, terminal and MCP hooks only -- so a write to a memory file is invisible to a hook on this agent. Fail mode is undocumented, so blocking rates best-effort rather than enforced. Payloads name their event in agent_action_name and carry the command, prompt and MCP fields inside tool_info (docs.devin.ai/desktop/cascade/hooks, read 2026-10-13, where the product is now Devin Desktop); the event is inferred from shape only when no name is present. The workspace file install writes, .windsurf/hooks.json, is now the legacy location: the same page says it is used only when .devin/hooks.json is absent or defines no hooks, so a repo whose .devin/hooks.json defines hooks does not run the agentseam ones.

## Every hook, one at a time

The story is held constant across agents so the pages compare: the same credential
heading for a memory file, the same failing test, the same prompt.

### 1. `prompt_submit` — called `pre_user_prompt` here

Enforcement: **best-effort**.

The agent sends:

```json
{
  "hook_event_name": "pre_user_prompt",
  "query": "remember my aws key so you can deploy later",
  "trajectory_id": "example"
}
```

which normalizes to:

```
event    = prompt_submit
tool     = pre_user_prompt
```

A `Decision.deny()` here produces:

```
policy violation
```

Exit code: `2`

### 2. `pre_tool` — called `pre_run_command` here

Enforcement: **best-effort**.

The agent sends:

```json
{
  "hook_event_name": "pre_run_command",
  "tool_info": {
    "command_line": "echo 'AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-KEY' >> AGENTS.md"
  },
  "trajectory_id": "example"
}
```

which normalizes to:

```
event    = pre_tool
tool     = pre_run_command
command  = echo 'AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-KEY' >> AGENTS.md
```

This is the gate, so every decision is worth seeing.

**`Decision.allow()`** — the handler is happy

_No output; the exit code carries the answer._

Exit code: `0`

**`Decision.deny()`** — the handler refuses

```
secret detected in file content
```

Exit code: `2`

**`Decision.escalate()`** — the handler wants a human

```
looks like a credential -- confirm? (this agent cannot prompt for confirmation; blocking instead)
```

Exit code: `2`

**`Decision.transform()`** — the handler wants the input changed

> reduced to `escalate`: this agent cannot transform

```
redacting the secret (this agent cannot rewrite tool input; blocking instead)
```

Exit code: `2`

**`Decision.warn()`** — the handler flags a concern

> reduced to `allow`: this agent cannot warn

_No output; the exit code carries the answer._

Exit code: `0`

**`Decision.vouch()`** — the handler actively approves

> reduced to `allow`: this agent cannot vouch

_No output; the exit code carries the answer._

Exit code: `0`
