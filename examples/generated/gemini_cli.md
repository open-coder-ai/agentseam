Top-level `decision: allow|deny|ask` + `reason` (not nested); rewrite merges via hookSpecificOutput.tool_input; exit 2 also blocks. Write tools are write_file/replace. Fail mode is not documented as closed, so pre_tool is rated best-effort rather than enforced. Source (read from a clone, 2026-08-28) corrected two things the hooks reference alone had settled wrongly. `ask` IS honoured, at BeforeTool only: hook-utils routes isAskDecision() to PolicyDecision.ASK_USER and calls resolveConfirmation with forcedDecision:'ask_user', which prompts even where the user's own policy rule would have auto-allowed -- a stronger ask than most vendors here can express, and this adapter was degrading it to a deny. At BeforeAgent/AfterAgent only isBlockingDecision() is consulted, so an ask there is inert and the degradation is right. Conversely `allow` is read NOWHERE: nothing in the tree tests for it and hookAggregator synthesises it when no hook objected, so unlike VS Code's permissionDecision:allow it cannot skip a confirmation.

## Every hook, one at a time

heading for a memory file, the same failing test, the same prompt.

### 4. `pre_tool` — called `BeforeTool` here

Enforcement: **best-effort**.

The agent sends:

```json
{
  "cwd": "/repo",
  "hook_event_name": "BeforeTool",
  "session_id": "example",
  "tool_input": {
    "content": "AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-KEY",
    "file_path": "AGENTS.md"
  },
  "tool_name": "write_file"
}
```

which normalizes to:

```
event    = pre_tool
tool     = write_file
path     = AGENTS.md
content  = AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-
```

This is the gate, so every decision is worth seeing.

**`Decision.allow()`** — the handler is happy

```json
{"decision": "allow"}
```

Exit code: `0`

**`Decision.deny()`** — the handler refuses

```json
{"decision": "deny", "reason": "secret detected in file content"}
```

Exit code: `0`

**`Decision.ask()`** — the handler wants a human

```json
{"decision": "ask", "reason": "looks like a credential -- confirm?"}
```

Exit code: `0`

**`Decision.rewrite()`** — the handler wants the input changed

```json
{"hookSpecificOutput": {"tool_input": {"content": "AWS_SECRET_ACCESS_KEY=<redacted>"}}}
```

Exit code: `0`

**`Decision.vouch()`** — the handler actively approves

> reduced to `allow`: this agent cannot vouch

```json
{"decision": "allow"}
```

Exit code: `0`
