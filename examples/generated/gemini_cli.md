# Gemini CLI

> Generated by `examples/generate.py`. Do not edit by hand.

Every block below is produced by running agentseam, so it is what this agent
actually gets -- not an illustration of what it might get.

## What agentseam claims about it

| | |
|---|---|
| tier | `block+rewrite` |
| enforcement at `pre_tool` | **best-effort** |
| can block | yes |
| can rewrite | yes |
| hook config | `.gemini/settings.json` |
| verified | 2026-08-26 (vendor hooks reference (docs/hooks/reference.md in google-gemini/gemini-cli), read from a clone) |

Top-level `decision: allow|deny` + `reason` (not nested); rewrite merges via hookSpecificOutput.tool_input; exit 2 also blocks. Write tools are write_file/replace. Fail mode is not documented as closed, so pre_tool is rated best-effort rather than enforced.

## 1. What `agentseam install` writes

Wiring one handler for the pre-tool gate. agentseam owns only the entries it adds;
an uninstall removes exactly those and leaves anything else in the file alone.

`.gemini/settings.json`

```json
{
  "hooks": {
    "BeforeTool": [
      {
        "hooks": [
          {
            "command": "python3 guard.py",
            "type": "command"
          }
        ]
      }
    ]
  }
}
```

## 2. The event the handler sees

The same situation for every agent: **a secret about to be written to a file.**

This agent sends:

```json
{
  "cwd": "/repo",
  "hook_event_name": "BeforeTool",
  "session_id": "example",
  "tool_input": {
    "content": "AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-KEY",
    "file_path": "GEMINI.md"
  },
  "tool_name": "write_file"
}
```

which agentseam normalizes to:

```
event    = pre_tool
tool     = write_file
path     = GEMINI.md
command  = None
content  = AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-
```

## 3. What each decision looks like coming back

### `Decision.allow()` -- the handler is happy

```json
{"decision": "allow"}
```

Exit code: `0`

### `Decision.deny()` -- the handler refuses

```json
{"decision": "deny", "reason": "secret detected in file content"}
```

Exit code: `0`

### `Decision.ask()` -- the handler wants a human

```json
{"decision": "deny", "reason": "looks like a credential -- confirm? (confirmation required; this agent cannot prompt from a hook)"}
```

Exit code: `0`

### `Decision.rewrite()` -- the handler wants the input changed

```json
{"hookSpecificOutput": {"tool_input": {"content": "AWS_SECRET_ACCESS_KEY=<redacted>"}}}
```

Exit code: `0`

## 4. Other primitives

**Permissions** -- `deny shell curl *` rendered into `.gemini/settings.json`:

```json
{}
```

> Not representable here: tools.exclude removes a whole tool from discovery; it cannot exclude only the invocations matching 'curl *'
