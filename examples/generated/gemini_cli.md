## Every hook, one at a time

heading for a memory file, the same failing test, the same prompt.

### 4. `pre_tool` — called `BeforeTool` here

Enforcement: **best-effort**.

The agent sends:

```json
{
  "cwd": "/repo",
  "hook_event_name": "BeforeTool",
  "session_id": "example",
  "tool_input": {
    "content": "AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-KEY",
    "file_path": "AGENTS.md"
  },
  "tool_name": "write_file"
}
```

which normalizes to:

```
event    = pre_tool
tool     = write_file
path     = AGENTS.md
content  = AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-
```

This is the gate, so every decision is worth seeing.

**`Decision.allow()`** — the handler is happy

```json
{"decision": "allow"}
```

Exit code: `0`

**`Decision.deny()`** — the handler refuses

```json
{"decision": "deny", "reason": "secret detected in file content"}
```

Exit code: `0`

**`Decision.ask()`** — the handler wants a human

```json
{"decision": "deny", "reason": "looks like a credential -- confirm? (confirmation required; this agent cannot prompt from a hook)"}
```

Exit code: `0`

**`Decision.rewrite()`** — the handler wants the input changed

```json
{"hookSpecificOutput": {"tool_input": {"content": "AWS_SECRET_ACCESS_KEY=<redacted>"}}}
```

Exit code: `0`
