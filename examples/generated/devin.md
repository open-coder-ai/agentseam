Speaks Claude Code's hook format almost exactly, and reads .claude/settings.json for hooks by default -- so a repo with Claude Code hooks is already running them under Devin. A block is top-level {"decision": "block"}, not permissionDecision. There is no ask in the vocabulary. Non-zero exit codes other than 2 are logged without blocking, so this fails OPEN. A SessionStart payload is indistinguishable from Claude Code's, and detect() refuses to guess between them.

## 1. What `agentseam install` writes

Wiring one handler for the pre-tool gate. agentseam owns only the entries it adds;
an uninstall removes exactly those and leaves anything else in the file alone.

`.devin/hooks.v1.json`

```json
{
  "PreToolUse": [
    {
      "hooks": [
        {
          "command": "python3 guard.py",
          "type": "command"
        }
      ]
    }
  ]
}
```

## 2. The event the handler sees

The same situation for every agent: **a secret about to be written to a file.**

This agent sends:

```json
{
  "hook_event_name": "PreToolUse",
  "prompt_id": "turn-1",
  "session_id": "example",
  "tool_input": {
    "content": "AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-KEY",
    "file_path": "AGENTS.md"
  },
  "tool_name": "write_file"
}
```

which agentseam normalizes to:

```
event    = pre_tool
tool     = write_file
path     = AGENTS.md
command  = None
content  = AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-
```

## 3. What each decision looks like coming back

### `Decision.allow()` -- the handler is happy

```json
{"decision": "approve"}
```

Exit code: `0`

### `Decision.deny()` -- the handler refuses

```json
{"decision": "block", "reason": "secret detected in file content"}
```

Exit code: `0`

### `Decision.ask()` -- the handler wants a human

```json
{"decision": "block", "reason": "looks like a credential -- confirm? (Devin cannot prompt for confirmation, so this is a block)"}
```

Exit code: `0`

### `Decision.rewrite()` -- the handler wants the input changed

```json
{"hookSpecificOutput": {"hookEventName": "PreToolUse", "updatedInput": {"content": "AWS_SECRET_ACCESS_KEY=<redacted>"}}}
```

Exit code: `0`
