Adapted (D2a): Vibe's payload is unambiguous (its snake_case hook types pre_tool, post_tool and post_agent are mapped by no other adapter, so the event name alone separates it), and its verdict is the flat_decision family's {decision: deny, reason}. A deny at pre_tool refuses the call and its reason becomes the tool error; at post_agent (the stop-like event) it asks the agent to retry, capped by Vibe at 3 retries per hook per user turn. Install writes [[hooks]] tables in Vibe's own keys: name (agentseam-<type>-<CRC-32 of the command>, unique because Vibe drops a duplicate name across files), type, match ("*" when no matcher is given, since the docs call it required at tool hooks) and command. Escalate degrades to a block: no hook verdict prompts. A transform at pre_tool is written as hook_specific_output.tool_input, which Vibe documents as a full replacement of the tool's arguments, re-validated against the tool's schema (a replacement that fails validation is denied); at post_agent a transform degrades to a block. Fail mode is configurable at pre_tool: open by default (a non-zero exit, timeout or malformed stdout warns and proceeds) and closed with strict = true, which install writes on its pre_tool rule only when called with fail_closed=True (`agentseam tier-table --fail-closed` reads that install). post_agent stays fail-open: Vibe rejects strict there. Project hooks load only in trusted folders, so a written config is not yet a live one. There is no prompt-submit or session event. Vibe also speaks ACP (vibe-acp), a client-agent protocol, not a hook surface; it is not claimed as one. Instruction files reach it through AGENTS.md. ### 1. `pre_tool` — called `pre_tool` here

Enforcement: **best-effort**.

The agent sends:

```json
{
  "cwd": "/repo",
  "hook_event_name": "pre_tool",
  "parent_session_id": null,
  "session_id": "example",
  "tool_call_id": "c1",
  "tool_input": {
    "content": "AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-KEY",
    "file_path": "AGENTS.md"
  },
  "tool_name": "write_file",
  "transcript_path": "/repo/s.jsonl"
}
```

which normalizes to:

```
event    = pre_tool
tool     = write_file
path     = AGENTS.md
content  = AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-
```

This is the gate, so every decision is worth seeing.

**`Decision.allow()`** — the handler is happy

_No output; the exit code carries the answer._

Exit code: `0`

**`Decision.deny()`** — the handler refuses

```json
{"decision": "deny", "reason": "secret detected in file content"}
```

Exit code: `0`

**`Decision.escalate()`** — the handler wants a human

```json
{"decision": "deny", "reason": "looks like a credential -- confirm? (Vibe cannot prompt for confirmation from a hook)"}
```

Exit code: `0`

**`Decision.transform()`** — the handler wants the input changed

```json

```

Exit code: `0`

**`Decision.warn()`** — the handler flags a concern

> reduced to `allow`: this agent cannot warn

_No output; the exit code carries the answer._
