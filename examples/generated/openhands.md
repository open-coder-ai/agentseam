PreToolUse, UserPromptSubmit and Stop can block; a block at Stop keeps the conversation going. The verdict is the flat {decision: deny, reason} body, and a bare allow is silence (exit 0). No rewrite and no ask: a transform or escalate degrades to a block, never to a silent pass. Fail-open: the docs say any exit code other than 0 and 2 is an error and the operation proceeds. The event name rides under event_type, not hook_event_name, which is what separates OpenHands payloads from every other adapter's. The cwd is working_dir. Known limit: file_editor's own sub-command (view, create, str_replace, insert, undo_edit) arrives in tool_input.command, the same key as terminal's shell command, so Event.command carries it for file_editor calls; a shell policy should check event.tool. The docs document only the project file; a user-level ~/.openhands/hooks.json exists in the SDK source, and a project file shadows it rather than merging. The standalone OpenHands-CLI repository says it is no longer actively maintained; the hooks docs still list the CLI. ### 4. `pre_tool` — called `PreToolUse` here

Enforcement: **best-effort**.

The agent sends:

```json
{
  "event_type": "PreToolUse",
  "session_id": "example",
  "tool_input": {
    "command": "create",
    "file_text": "AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-KEY",
    "path": "AGENTS.md"
  },
  "tool_name": "file_editor",
  "working_dir": "/repo"
}
```

which normalizes to:

```
event    = pre_tool
tool     = file_editor
path     = AGENTS.md
command  = create
content  = AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-
```

This is the gate, so every decision is worth seeing.

**`Decision.allow()`** — the handler is happy

_No output; the exit code carries the answer._

Exit code: `0`

**`Decision.deny()`** — the handler refuses

```json
{"decision": "deny", "reason": "secret detected in file content"}
```

Exit code: `0`

**`Decision.escalate()`** — the handler wants a human

```json
{"decision": "deny", "reason": "looks like a credential -- confirm? (OpenHands cannot prompt for confirmation)"}
```

Exit code: `0`

**`Decision.transform()`** — the handler wants the input changed

> reduced to `escalate`: this agent cannot transform

```json
{"decision": "deny", "reason": "redacting the secret (OpenHands cannot modify a tool call)"}
```

Exit code: `0`

**`Decision.warn()`** — the handler flags a concern

> reduced to `allow`: this agent cannot warn

_No output; the exit code carries the answer._

Exit code: `0`

**`Decision.vouch()`** — the handler actively approves
