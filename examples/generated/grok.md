## What agentseam claims about it

| | |
|---|---|
| tier | `block` |
| enforcement at `pre_tool` | **best-effort** |
| can block | yes |
| can rewrite | no |
| hook config | `.grok/hooks/agentseam.json` |
| verified | 2026-08-26 (vendor hooks documentation read directly (events, script contract, exit codes)) |

PreToolUse is the ONLY blocking event; everywhere else stdout is ignored. No rewrite: the vocabulary is {decision: deny, reason} and nothing more. Fails OPEN -- timeouts, crashes and malformed output are recorded and the call proceeds. Payload fields are camelCase (hookEventName, toolName) while event values stay PascalCase, which is what separates it from Claude Code, Codex and VS Code Copilot. Reads .claude/settings.json and .cursor/hooks.json too. Project hooks need trust (/hooks-trust or --trust) before they run, so a written config is not yet a live one.

## 1. What `agentseam install` writes

an uninstall removes exactly those and leaves anything else in the file alone.

## 2. The event the handler sees

The same situation for every agent: **a secret about to be written to a file.**

This agent sends:

```json
{
  "hookEventName": "PreToolUse",
  "sessionId": "example",
  "toolInput": {
    "content": "AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-KEY",
    "file_path": "AGENTS.md"
  },
  "toolName": "Write",
  "workspaceRoot": "/repo"
}
```

which agentseam normalizes to:

```
event    = pre_tool
tool     = Write
path     = AGENTS.md
command  = None
content  = AWS_SECRET_ACCESS_KEY=EXAMPLE-PLACEHOLDER-NOT-A-
```

## 3. What each decision looks like coming back

### `Decision.allow()` -- the handler is happy

_No output. Exit code alone carries the answer here._

Exit code: `0`

### `Decision.deny()` -- the handler refuses

```json
{"decision": "deny", "reason": "secret detected in file content"}
```

Exit code: `0`

### `Decision.ask()` -- the handler wants a human

```json
{"decision": "deny", "reason": "looks like a credential -- confirm? (Grok cannot prompt for confirmation)"}
```

Exit code: `0`

### `Decision.rewrite()` -- the handler wants the input changed

> reduced to `ask` by the dispatcher: this agent cannot rewrite

```json
{"decision": "deny", "reason": "redacting the secret (Grok cannot modify a tool call)"}
```

Exit code: `0`
