> Generated by `examples/generate.py`. Do not edit by hand.

supports** -- the payload it sends, the normalized event a handler sees, and what
comes back. The story is held constant across agents so the pages compare.

to do.** The `evidence` column says which for each agent. Only one row here rests on
a live run; most are read from vendor documentation, and vendors change hook surfaces
without notice. Verify against your own installation before relying on any of it.
