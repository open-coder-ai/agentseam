# Support

- **Bug or wrong behaviour** → [open an issue](https://github.com/open-coder-ai/agentseam/issues/new/choose)
- **An agent's hooks changed / a matrix row is wrong** → open an issue with the
  vendor's doc link or a captured payload; matrix corrections are prioritised
- **Adding an agent** → see [CONTRIBUTING.md](CONTRIBUTING.md); adapters are meant to be cheap
- **Security** → do not open an issue; see [SECURITY.md](SECURITY.md)

Not a support channel for the agents themselves — for Claude Code, Cursor, Copilot and
friends, use their own issue trackers.
